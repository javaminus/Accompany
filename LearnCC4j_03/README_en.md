# LearnCC4j_03: Spring AI Planning Agent

> A teachable, debuggable, and extensible multi-step execution framework — enabling LLMs to truly "act step-by-step"

## 🌟 Overview

`LearnCC4j_03` is the third hands-on project in the *AI Programming Companion* series, focused on the **engineering implementation of a Planning Agent**. It avoids black-box agent frameworks, instead building a **controllable, observable, and pedagogically sound** execution environment using **Spring AI + custom tool protocols + explicit state management**.

Core goals:
- ✅ Automatically decompose ambiguous user requests (e.g., "Generate a README for this project") into atomic steps (scan directory → read files → write content → verify);
- ✅ **Enforce single-step progression**: After each step, the plan is *refreshed*, ensuring decisions are always grounded in the latest context;
- ✅ Use `todoTool` to enforce "one-step-at-a-time + explicit state", replacing unreliable free-form chain-of-thought reasoning.

## ⚙️ Design Philosophy & Key Insights

### Why is `todoTool` the soul of this project?
- **Single-step lock (`in_progress`)**: Only one task may be `in_progress` at any time — eliminating concurrency chaos and state drift;
- **Dynamic replanning (`refresh the plan`)**: Every completed step triggers full plan regeneration, allowing the agent to react to intermediate outcomes (e.g., switch to `bashTool` if a file is missing);
- **Tools as contracts (not just functions)**: Each tool declares strict semantic requirements (e.g., `readFileTool` requires `path`, `writeFileTool` requires `content`), and system prompts rigorously constrain invocation syntax.

### Memory-Prompt Co-design
- `MessageChatMemoryAdvisor` intercepts all messages and injects a live snapshot of the current `todoTool` state;
- The system prompt explicitly declares the working directory (`F:\learn_ai\Accompany`), available tools, and invocation rules — placing the LLM inside a *controlled sandbox*.

## 🛠️ Tech Stack

| Layer | Component | Notes |
|-------|-----------|-------|
| **AI Core** | Spring AI 1.0.0-M5 | Provides `ChatClient`, `ChatMemory`, `Tool` abstractions |
| **Runtime** | Spring Boot 3.3.x + Java 17 | Jakarta EE 9+, GraalVM native image ready |
| **Memory** | `InMemoryChatMemory` + custom `Advisor` | Session-scoped context + dynamic state injection |
| **Tooling** | `bashTool`, `readFileTool`, `writeFileTool`, `editFileTool`, `todoTool` | All registered as Spring Beans, compliant with `FunctionCallback` contract |

## ▶️ Quick Start

```bash
# 1. Enter the project directory
cd LearnCC4j_03

# 2. Launch the app (defaults to local Ollama llama3:8b)
mvn spring-boot:run

# 3. Issue commands in the CLI (Chinese supported)
s03 >> Please generate a professional bilingual README for this project
```

✅ Success indicator: Console prints `✅ README_zh.md and README_en.md generated`, and both files contain complete, well-structured content.
